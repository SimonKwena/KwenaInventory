Welcome to Kwena Inventory

Borrow and return instruments and equipment. Here's a quick tour of what you can do.

{# ---- Admin / Superadmin: Dashboard (step 1 for admin+) ---- #} {% if user_role == "admin" or user_role == "superadmin" %}

The Dashboard

The Dashboard gives the full picture: total stock, overdue returns, maintenance, and announcements. Use it to spot overdue gear at a glance.

{% endif %} {# ---- Quick Action (all roles) ---- #}

The Quick Action

The Quick Action is your all-in-one workspace. Pick an action — Book Ahead, Check Out, or Check In — choose a location first, then scan a QR code or pick items. Your request generates a slip code straight away.

{# ---- Browse and request (all roles) ---- #}

Browse and request

From Browse Items you can see everything available. Add what you need to your cart, then submit a Book Ahead or Check Out request. Your request waits for an admin to approve it before any stock moves.

{# ---- Maintenance (teacher, staff, admin, superadmin) ---- #} {% if user_role == "teacher" or user_role == "staff" or user_role == "admin" or user_role == "superadmin" %}

Report maintenance

Found a fault? Use the Maintenance tab to report broken or serviced gear. Admin will see it and arrange a repair. You can track the status of your own reports.

{% endif %} {# ---- Student: check in & track ---- #} {% if user_role == "student" %}

Check in and track

To return gear, open Check In, pick the loan (by slip code) and set its condition. Your Home page keeps your borrowed gear, pending requests, and reservations in one place.

{% endif %} {# ---- Guest: pending approval + full access ---- #} {% if user_role == "guest" %}

Pending approval

An admin must approve your requests before any stock moves. You'll get a notification once it's approved, and your slip code is your reference at the counter.

Full access with an account

For direct check-outs and automatic history, sign in with a @kwenamusic.co.za Google account, or ask staff to set up a local account.

{% endif %} {# ---- Admin / Superadmin: Updates ---- #} {% if user_role == "admin" or user_role == "superadmin" %}

Updates

Use Manage → Updates to post announcements and keep everyone informed about news, closures, or policy changes.

{% endif %} {# ---- Staff / Admin / Superadmin: Requests ---- #} {% if user_role == "staff" or user_role == "admin" or user_role == "superadmin" %}

Requests

Manage → Requests shows pending member requests. You can view them to see what members are asking for.

{% endif %} {# ---- Superadmin: approve & manage ---- #} {% if user_role == "superadmin" %}

Approve and manage

Approve member requests, hand over reservations, manage items, post announcements, and take stock from the Manage menu. You can also manage users from the admin tools.

{% endif %} {# ---- Push notifications (all roles) ---- #}

Push notifications

Turn on alerts in My account → Notifications so you don't miss request updates, overdue reminders, and announcements.

{# ---- Your slip code (required for all roles) ---- #}

Your slip code

Every request gets a slip code like KW-0042. Show it at the counter when you collect gear, and again when you bring it back. You can email or print the slip, or print a tech rider, right from your Home page or requests list.
